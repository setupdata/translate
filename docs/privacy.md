# 隐私与数据说明

如意翻译采用客户端直连方式。插件没有自有账号系统、共享密钥、模型额度、中转服务、翻译历史或遥测平台。用户在确认后，由 preload 使用用户选择的服务配置和 API Key，从本机直接请求模型服务。

## 会发送到模型服务的数据

标准翻译会发送当前源文本、目标语言、命中的术语、用户选择的行业配置和参考译例，以及附加翻译要求。精译还会在分析、翻译、准确性审校、语言审校和必要的定向修订阶段，多次发送当前任务所需的分析结果、审校意见和相关段落。每次开始前，页面会显示完整翻译地址、协议、数据范围和预计调用次数。

“测试连接”只在用户点击后发送固定短文本。“获取模型”只在用户点击后访问页面显示的模型列表地址；需要鉴权的配置会由 preload 加入对应请求头。React 页面不会获得完整 API Key 或 Authorization 请求头。

远程服务只能使用 HTTPS，本机回环地址可以使用 HTTP。同源重定向最多跟随三次，跨域重定向会在转发 API Key 或翻译资料前停止。模型服务如何处理、保留或再利用请求内容，以及由此产生的费用和限流，都受服务提供方条款约束，插件无法控制。

## 本机保存的数据

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| 服务配置名称、地址、协议、模型、模型列表缓存、默认目标语言、默认质量模式、默认附加要求、通知选择和首次确认状态 | uTools 本地数据库 | 不含完整 API Key 和翻译正文 |
| API Key | uTools `dbCryptoStorage` | 页面只显示掩码，不回填完整值 |
| 术语库、行业配置、参考译例 | uTools `dbCryptoStorage` | 只在用户保存后写入 |
| 最近十次请求的性能汇总 | 服务配置元数据 | 仅含首个输出时间、完成耗时、输出码点数、平均速度、翻译方式和分段数 |
| 当前源文本、译文、本次术语、附加要求、风险、分析、审校和修订状态 | 插件进程内存 | 不写入数据库、文件、日志或翻译历史，进程结束后丢失 |

性能汇总不含源文本、译文、用户标识或单次请求日志，不会发送给模型服务。项目也不会读取或写入质量评测缓存。

`dbCryptoStorage` 可以降低密钥和业务数据以明文保存的风险，但客户端直连不能保证密钥绝对不可提取。本机高权限程序、调试工具、被篡改的插件或运行环境仍可能读取进程中的密钥和请求内容。

## uTools 同步

uTools 没有保证 `dbCryptoStorage` 一定排除在数据同步之外。用户开启同步后，普通设置、服务元数据、API Key、术语库、行业配置或参考译例都可能形成远端或其他设备副本。插件只能删除它能够访问的本机键，不能替用户清除 uTools 远端或其他设备上的副本；这些副本需要在 uTools 的同步数据管理中另行处理。

## 剪贴板、通知和后台运行

插件不会主动读取、监听或轮询剪贴板。全局快捷键由用户在 uTools 中明确配置和触发；复制译文或粘贴回原窗口也必须点击相应按钮。系统通知只包含“完成”“失败”或“超时”等通用状态，不含源文、译文、术语、参考译例或 API Key。点击通知只返回当前翻译，不会自动复制或粘贴。

普通隐藏后，当前请求会在插件进程仍存活时尽力继续，但不是可靠的离线任务。断网、退出 uTools、结束进程、休眠、强制终止或更新都可能中断请求。进程结束后，当前翻译不会持久化，也不能由新进程恢复。

## 删除和恢复的范围

用户可以单独删除 API Key，也可以删除一项服务配置及其 API Key、模型缓存和性能汇总。术语库、行业配置和参考译例可以在各自页面删除。

“恢复所有设置”会在二次确认后取消当前任务，删除插件能够控制的服务配置、API Key、缓存、默认项、术语库、行业配置、参考译例、通知设置、确认状态和当前翻译，并重新建立一个未配置 API Key 的 DeepSeek Flash 预设。删除本地数据不能删除模型服务已经保留的请求，也不能保证删除 uTools 已同步到远端或其他设备的副本。

相关设计边界见 [ADR-0001：客户端使用用户密钥直连模型服务](adr/0001-client-direct-model-access.md)。操作步骤见 [用户手册](user-manual.md)。
