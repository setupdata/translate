# 如意翻译用户手册

本手册适用于 0.1.x 版本。当前版本由用户自行配置模型服务和 API Key，插件从本机直接请求该服务，不提供账号、共享密钥、模型额度或中转服务器。

## 安装与入口

安装正式或本地测试 UPXS 后，可以通过以下入口打开插件：

- 在 uTools 中输入“如意翻译”“翻译”或“fy”，进入翻译页；
- 选中文字后使用“用如意翻译”匹配指令，文本会带入翻译页并开始准备翻译；
- 输入“如意翻译设置”，进入设置页。

设置页的“配置全局快捷键”按钮会打开 uTools 的全局快捷键设置，并定位到“用如意翻译”。只有用户明确触发该快捷键时，uTools 才会复制当前选中文字并交给匹配指令。插件本身不会读取、监听或轮询剪贴板。

uTools 的快捷键配置方法可参阅[官方全局快捷键说明](https://www.u-tools.cn/docs/guide/global-shortcut.html)。

本地开发和 UPXS 打包方法见 [本地打包说明](../artifacts/README.md)。

## 配置模型服务

首次使用时，插件会建立一个未填写 API Key 的 DeepSeek Flash 预设。可以直接编辑它，也可以在设置页新增自定义服务。

DeepSeek 官方配置固定使用官方 Chat Completions 地址和 Bearer 鉴权，用户可以修改模型 ID、流式响应和 API Key。自定义配置需要填写配置名称、协议、完整翻译地址、模型列表地址、鉴权方式和模型 ID；协议可以选择 Chat Completions 或 Responses。远程服务必须使用 HTTPS，只有 `localhost`、`127.0.0.1` 和 `::1` 等本机回环地址可以使用 HTTP。

API Key 输入框不会回填已保存的完整值，只显示掩码。留空保存会沿用已有密钥，也可以单独点击“删除 API Key”。自定义服务可以选择不鉴权。

“测试连接”只在用户点击后发送固定短文本，可能产生少量模型费用。“获取模型”也只在点击后访问页面显示的完整模型列表地址，不会替换用户手填的模型。服务费用、限流、可用性及数据处理规则由服务提供方决定；如无可靠价格信息，插件只显示调用次数，不估算金额。

## 发起翻译

源文本最多为 10,000 个 Unicode 码点。普通 Enter 只会换行；Windows 和 Linux 可按 `Ctrl+Enter` 开始，macOS 可按 `Command+Enter` 开始；翻译期间按 Escape 或点击“取消翻译”会尽力取消请求并保留已经收到的部分译文。

翻译前可以选择目标语言、行业配置、附加要求、质量模式和长文本并发设置，也可以添加只用于本次任务的术语。修改这些内容不会自动联网；已有译文会标记为对应旧设置，在重新翻译前不能粘贴回原窗口。

标准模式通常发起一次翻译调用。精译模式先分析全文，再翻译一次或按段翻译，随后同时进行一次准确性审校和一次语言审校；有需要时最多再定向修订一次。页面会在每次开始前显示“1 次分析 + N 次翻译 + 2 次并行审校 + 最多 1 次修订”的计划。DeepSeek 官方配置可以逐项记住思考模式选择；开启后，精译各阶段的等待时间和费用都可能增加。

长文本并发加速默认关闭。用户开启后可以选择 1 至 6 个并发请求，插件按源文顺序合并结果；无法安全切分时会说明原因并回退到全文翻译。精译即使分段，也只分析全文一次，并在译文合并后审校整篇。

## 术语、行业配置和参考译例

设置页可以维护通用术语库、行业配置和参考译例。术语库支持逐项编辑，也支持 UTF-8 CSV 整体导入和导出；导入前会显示字段映射、重复、冲突和语言方向问题，只有用户确认后才会写入。

行业配置可以关联多个术语库，并保存行业、文档类型、读者、文体和保留规则。参考译例必须关联行业配置和语言方向。翻译时，插件只发送当前源文本实际命中的术语；参考译例先在本地按文本相似度筛选，再由用户逐条确认，最多发送三条。相同优先级的严格术语发生冲突时，插件会在联网前要求用户选择本次采用的译法。

## 首次发送确认

每项服务第一次发送翻译数据前，确认窗口会显示服务名称、完整翻译地址、协议、将发送的数据范围和调用次数。精译第一次使用该服务时，还会说明同一服务将多次处理本次资料。用户应避免提交无权向模型服务提供的敏感内容。

确认只针对确认窗口中的规范化完整地址。修改服务地址后需要重新确认；跨域重定向会在转发 API Key 或翻译资料前停止。

## 当前翻译、后台运行和通知

源文本、译文、本次术语、附加要求、风险和精译中间状态只保留在当前插件进程内。普通隐藏后，只要进程仍存活，翻译会尽力继续；重新打开同一进程可以恢复当前翻译。携带新文本进入插件会取消并替换旧任务。“清空当前内容”会取消当前请求并删除这组内存数据。

后台翻译仍受 60 秒无数据超时和 10 分钟总时限约束。完成、失败或超时后，插件默认发送不含用户内容的通用系统通知，可以在设置中关闭；点击通知只会返回当前翻译，不会自动复制或粘贴。

后台运行不是可靠的离线任务。断网、退出 uTools、结束插件进程、系统休眠、强制终止或更新插件都可能中断请求。进程结束后，当前翻译不能在新进程中恢复。

## 复制、粘贴和风险提示

“复制译文”只在用户点击后复制纯文本，并保持插件窗口可见。“粘贴回原窗口”只在用户点击后隐藏插件并粘贴纯文本。插件不会自动执行这两项操作。

如果本地检查发现数字、链接、占位符、代码、Markdown、保护内容或严格术语存在确定性严重风险，直接粘贴会被禁用；用户确认会人工复核后仍可复制。启发式风险会显示供人工检查，但不会自动阻止复制。失败或取消后的部分译文可以复制，不能直接粘贴。

## 删除数据和恢复设置

服务配置可以逐项删除，删除时会一并移除该配置的 API Key、模型列表缓存和性能汇总。术语库、行业配置和参考译例也有各自的删除确认。

设置页的“恢复所有设置”需要二次确认。它会取消当前任务，删除插件能够控制的服务配置、API Key、缓存、默认项、术语库、行业配置、参考译例、通知设置、确认状态和当前翻译，然后重新建立一个未配置 API Key 的 DeepSeek Flash 预设。操作不可撤销。

恢复设置不能删除模型服务已经保留的请求，也不能保证删除 uTools 已同步到远端或其他设备的数据。详细范围见 [隐私与数据说明](privacy.md)。

## 常见问题

如果页面提示服务配置缺失、停用或需要迁移，请进入“如意翻译设置”重新编辑受影响的地址、协议、模型和密钥；插件不会回显旧的完整密钥。如果连接测试成功而翻译失败，应先核对翻译地址是否为完整接口地址、协议是否匹配、模型 ID 是否可用，再查看页面显示的稳定错误信息。

本地回环测试可以使用仓库提供的模拟服务，但它不代表真实 HTTPS 服务、系统通知、剪贴板或三平台 uTools 行为已经通过实机验收。当前验收状态见 [三平台验收记录](platform-acceptance.md)。
